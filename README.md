# IS 310 Coding Assignments

This repository contains my homework assignments for IS 310: Culture as Data Spring 2026 at the University of Illinois Urbana-Champaign.

## Repository Contents

The assignments in this repository focus on building foundational skills with the command line, Git, GitHub, Python scripting, and basic web development.

Included projects:

### Command Line Maze

A terminal-based maze activity designed to practice navigating directories and using basic shell commands.

### init-is310

An initialization assignment used to set up the course environment and practice version control basics.

### Command Line Data Curation

A Python-based command-line interface (CLI) application that allows users to manually enter movie data directly in the terminal.

For this assignment, I created a CLI app using the **Rich** library to display formatted output in the terminal. The program supports movie data entry and reinforces the following concepts:

- Python scripting
- Functions and loops
- Conditional statements
- Command-line interaction
- Virtual environments and package management
- Using third-party Python libraries (Rich)

### Source and Style

Assignments focused on inspecting a cultural website using browser developer tools and creating an HTML page that presents a digitized cultural object.

## Purpose

This repository serves as a central place to organize, submit, and track my coding assignments throughout the semester.
