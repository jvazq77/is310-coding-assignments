# BestsellersAndTopRankedNovels

This folder contains my exploratory data analysis notebook for the Goodreads Top 500 Novels dataset and the New York Times Hardcover Fiction Bestsellers dataset.

## Overview
In this project, I use Pandas and Altair to explore patterns in genre, publication year, Goodreads ratings, and bestseller overlap. The purpose of the notebook is to use exploratory data analysis to better understand what kinds of books are represented in these datasets and what trends stand out.

## Notebook
- `BestsellersAndTopRankedNovels.ipynb`

## Questions Explored
- Which genres appear most often in the Top 500 Novels dataset?
- Do some genres have higher average Goodreads ratings than others?
- How much overlap exists between top ranked novels and New York Times bestsellers?
- How do genres appear across publication years?

## Datasets
This notebook uses remote dataset URLs.

- Goodreads Top 500 Novels dataset from the Responsible Datasets in Context Project
- New York Times Hardcover Fiction Bestsellers dataset from the Post45 Data Collective

## Tools
- Python
- Pandas
- Altair

## Contents
The notebook includes:
- loading and previewing the data
- checking missing values
- cleaning title formatting for merging
- merging the two datasets
- creating Altair visualizations
- interpreting patterns and findings

## Notes
No local data files are required as long as the notebook has internet access.
